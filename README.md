# Cyberpunk2077

Mods for Cyberpunk 2077.
- [Nexus link](https://www.nexusmods.com/profile/DeepBlueFrog/mods?gameId=3333)

---

## Limited Encumbrance Series

Replace the carry weight system with a slot-based encumbrance model, with optional backpack items and a store to purchase them.

**Limited Encumbrance** (`LimitedEncumbrance`)
- Replaces carry weight with a fixed number of inventory slots; supports dynamic capacity changes through bag modifiers. 

**Limited Encumbrance Backpack** (`LimitedEncumbranceBackpack`)
- Adds craftable/buyable backpack items (MrBunny, Caibro) that expand your encumbrance capacity.

**Limited Encumbrance Backpack Store** (`LimitedEncumbranceBackpackStore`)
- In-game store UI for purchasing backpacks to use with the encumbrance system.

---

## Vehicle Mods

**Claim Vehicles / N.C.L.A.I.M.S** (`ClaimVehicles`)
- Permanently claim and store stolen vehicles; configure summon mode (Normal, Last, Random, Delamain, Favorites, All).


**Vehicle Fast Travel** (`VehicleFastTravel`)
- Enables fast travel through vehicles with a built-in malware system and optional 'V' key restoration for vehicle recall.

**Vehicles Services UI** (`VehiclesServicesUI`)
- In-game UI panel for vehicle services and maintenance options.

---

## Live A Little Series

Quality-of-life improvements with multilingual support (8 languages), offering various gameplay tweaks with optional timer mechanics.

**Live A Little** (`LiveALittle`)
- Core QoL mod with gameplay adjustments and full localization support.

**Live A Little Timers** (`LiveALittleTimers`)
- Extends Live A Little with timer-based event triggers.

**Live A Little — Militech Fix** (`LiveALittleMilitechFix`)
- Targeted fix for Militech-related interactions within Live A Little.

**Live A Little — Phantom Liberty** (`LiveALittlePL`)
- Phantom Liberty expansion support for Live A Little with additional localization.

**Live A Little PL Timers** (`LiveALittlePLTimers`)
- Phantom Liberty variant of Live A Little with timer functionality.

---

## Santa Muerte Series

Resurrection and permadeath system with configurable difficulty, death animations, and energy/nerve impact mechanics.

**Santa Muerte** (`SantaMuerte`)
- Adds a resurrection system with Low/Medium/High difficulty modes; tracks deaths and limits revives dynamically.

**Santa Muerte Permadeath Bridge** (`SantaMuertePermadeathBridge`)
- Companion addon enabling permadeath mode for Santa Muerte, blocking resurrection on final death.

---

## ReShade & Visual

Tools to drive ReShade preset switching from within the game's scripting layer.

**ReShade Bridge** (`ReshadeBridge`)
- Red4ext plugin that bridges ReShade's addon API with REDscript, allowing runtime preset and effect switching.

**ReShade Bridge Source** (`ReshadeBridgeSource`)
- C++ source code for the ReShade Bridge plugin (CMake project using the Red4ext SDK and ReShade API).

**Conditional ReShade Optics** (`ConditionalReshadeOptics`)
- Automatically switches ReShade presets based on game state (VR detection, cinematic scenes, etc.) using heartbeat monitoring.

## Loot & Inventory

**Diverse Loot** (`DiverseLoot`)
- Diversifies loot tables across all factions and creature types (Arasaka, Militech, Maelstrom, animals…) with separate epic/legendary drop pools.

**Junk Mods Disassembly** (`JunkModsDisassembly`)
- Lets you disassemble junk items into crafting components, with quality filtering and repeat-disassembly modes.

**Immersive Components** (`ImmersiveComponents`)
- Adjusts crafting component behaviour for a more immersive feel; includes multilingual localization.

**Adaptive Sliders** (`AdaptiveSliders`)
- Makes the item-quantity picker default to the maximum value when dropping or selling items.

**Diverse Death Screens** (`DiverseDeathScreens`)
- Randomizes death screen effects and optionally enables longer death animations for variety.

## Stores & Cosmetics

**Lara Croft Explorer's Store** (`LaraCroftExplorersStore`)
- In-game store stocked with Lara Croft–themed explorer gear and accessories.

**Moon Bunny** (`MoonBunny`)
- Archive-based cosmetic mod adding Moon Bunny themed items.

## Patches & Utilities

**Cinematic Immunity** (`CinematicImmunity`)
- Grants temporary invulnerability during scripted cinematic sequences (Johnny possession, impersonations, VR tutorial, etc.).

**Patch — Lightweight Difficulty Enhancer** (`patchLightweightDifficultyEnhancer`)
- CET-based patch for Lightweight Difficulty Enhancer; tweaks ammo caps, stat scaling, pricing, and item weights.

**Patch — Limited Fast Travel** (`patchLimitedFastTravel`)
- Restricts or modifies fast travel availability to increase travel immersion.

**Small Patches** (`SmallPatches`)
- Collection of minor fixes and tweaks, including ammunition balance adjustments (DecentAmmo) and a navigation overlay (NavMod) with real-time position tracking.
